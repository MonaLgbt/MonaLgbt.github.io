## Ablenkungsfreies Schreiben

Wer oft am Computer arbeitet, kennt das Problem.  
Man kann so viel sehen und entdecken.  
Dann ist es manchmal schwer bei einer Aufgabe zu bleiben.  

Aber es gibt besondere Schreib-Programme.  
Sie haben einen Modus für wenig Ablenkung.  
Der heißt: ablenkungsfreie Oberfläche.  
Das bedeutet: Es gibt nur das Textfeld.  
Es gibt keine Symbole oder Menüs.  
So können Sie sich besser auf das Schreiben konzentrieren.  

Auch bekannte Autoren machen das.  
Zum Beispiel: George R.R. Martin.  
Er hat die Bücher von Game of Thrones geschrieben.  
Oder: Jussi Adler-Olsen.  
Er schreibt Krimis mit der Figur Carl-Mørck.  

Sie benutzen alte Schreib-Programme am Computer.  
Die Programme heißen WordStar und WordPerfect.  
Auch diese Programme helfen beim Konzentrieren.  
Denn sie zeigen nur das Nötigste auf dem Bildschirm.  
So können Sie gut schreiben.
