# Was ist Markdown?

Markdown ist eine einfache Methode oder Art, Texte schöner zu machen.  
Das macht den Text verständlicher.  
Man kann Markdown schon im Quelltext gut lesen.  
Die wenigen Extra-Zeichen stören nicht viel.  
Aber nur in der fertigen Ansicht ist es wirklich gut.  
Du schreibst besondere Zeichen,  
und der Text wird dann:

❶ fett mit  
```
**Beispiel-fett**
```

**Beispiel-fett**

❷ kursiv mit  
```
*Beispiel-kursiv*
```

*Beispiel-kursiv*

❸ Liste mit

```
- Beispiel A
- Beispiel B
```

- Beispiel A
- Beispiel B

❹ Überschrift mit  
```
### Beispiel-Überschrift
```

<font size="5">
<span style="color:black">
<left>

Beispiel-Überschrift

</left>
</span>
</font>
<br>

Markdown ist eine **Regel**, wie man Texte schön macht.  
Und es ist eine Sprache,  
die viele Programme verstehen.  
Sogar einige Messenger verstehen ein bisschen Markdown.

**Zum Beispiel:**

- Chat-Apps, 
- Webseiten oder 
- Notiz-Apps. 

Du kannst Markdown in vielen Textfeldern verwenden.  
Es wird oft unterstützt aber selten erklärt.  
Darum probiere es einfach aus.

## Was ist Markdown auch?

[John Gruber](https://en.wikipedia.org/wiki/John_Gruber) hat [Markdown](https://daringfireball.net/projects/markdown/) erfunden.  
Die Erklärung von Markdown hatte viele offene Fragen.  
Viele Entwickler nutzten Markdown unterschiedlich.  
Manche machten Fehler, weil es nicht genau erklärt war.  
Dadurch gab es viele verschiedene [Versionen](https://en.wikipedia.org/wiki/Markdown) von Markdown.

**An dieser Stelle fällt euch vielleicht der bekannte XKCD-Strip zu Standards ein:**

![standards](../assets/standards.png)

*Wenn wir 14 konkurrierende Standards haben und einen neuen Standard erfinden, um dieses Problem zu lösen, haben wir danach 15 konkurrierende Standards.*

Aber das Grund-Prinzip ist immer gleich.  
Man braucht nur normalen Text.  
Außerdem benutzt man ein paar Zeichen.  
Zum Beispiel Sternchen oder Rauten.  
Diese Zeichen machen Text besonders.  
So kann man Texte einfach gestalten.

## Was ist Markdown nicht?

- Es ist **kein** Programm
- Es ist **keine** App

Aber es gibt viele Programme und Apps, die Markdown nutzen können.  
Auch moderne KI-Programme nutzen Markdown sehr gerne.
