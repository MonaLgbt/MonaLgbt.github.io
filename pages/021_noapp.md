# Was ist Markdown?

Markdown ist eine einfache Methode oder Art, Texte schön zu machen.  
Du schreibst besondere Zeichen,  
und der Text wird dann:

❶ fett mit  
`**Beispiel-Text**`

**Beispiel-Text**

❷ kursiv mit  
`*Beispiel-Text*`

*Beispiel-Text*

❸ Überschrift mit  
`### Beispiel-Text`

<font size="5">
<span style="color:black">
<left>

**Beispiel-Text**

</left>
</span style>
</font size>

❹ Liste mit  
`- Beispiel-Text`

- Beispiel-Text


Markdown ist eine **Regel**, wie man Texte schön macht.  
Und es ist eine Sprache,  
die viele Programme verstehen.  
Sogar einige Messenger verstehen ein bisschen Markdown.

**Zum Beispiel:**

- Chat-Apps, 
- Webseiten oder 
- Notiz-Apps. 

Du kannst Markdown in vielen Textfeldern verwenden.  
Es wird oft unterstützt aber selten erklärt.  
Darum probiere es einfach aus.

## Was ist Markdown nicht?

- Es ist **kein** Programm
- Es ist **keine** App

Aber es gibt viele Programme und Apps, die Markdown nutzen können.  
Auch moderne KI-Programme nutzen Markdown sehr gerne.
