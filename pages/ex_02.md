## Tabellen mit Ausrichtung

links  | rechts | mittig
-------|-------:|:---:
101    | 2      | 301
1      | 201    | 3


```
Mit diesem kleinen Skript kann man schnell prüfen, 
ob die Webseite breiter ist als das sichtbare Browserfenster.

Zum Beispiel:
innerWidth = 1200
scrollWidth = 1500

→ Irgendein Element ist 300 Pixel zu breit 
und verursacht horizontales Scrollen.
```

```html
<script>
document.body.insertAdjacentHTML(
  'beforeend',
  '<p>innerWidth=' + window.innerWidth +
  ' scrollWidth=' + document.body.scrollWidth + '</p>'
);
</script>
```
