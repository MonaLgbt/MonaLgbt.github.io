## Überall Markdown schreiben

Zum Beispiel:  
Sie können Markdown in Word benutzen.  
Sie öffnen das Programm Word.  
Dann schreiben Sie Ihren Text.  
Sie schreiben den Text mit Hilfe von Markdown.  
Aber:  
Sie sehen in Word keinen schönen, fertigen Text.  
Sie sehen nur den normalen Text mit Zeichen von Markdown.  
Das ist aber nicht schlimm.  
Sie können den Text einfach speichern.  
Zum Beispiel:  
Sie speichern die Datei unter dem Namen „Mein Text.txt“.  

Wenn Sie später weiterarbeiten möchten,  
nutzen Sie einen Markdown-Editor.  
Ein Markdown-Editor ist ein Programm.  
Das Programm zeigt den Text schön und fertig an.  

Manche Messenger können auch Markdown erkennen.  
Ein Messenger ist ein Programm zum Chatten.  
Zum Beispiel sind WhatsApp und Telegram Messenger.  
Manche Messenger zeigen den Text schön an,  
wenn Sie Markdown benutzen.  
Probieren Sie es einfach aus.  
Vielleicht funktioniert es bei Ihrem Messenger.
